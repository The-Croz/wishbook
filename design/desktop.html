Wishbook on a desktop

The red cover becomes a left rail, the white page becomes a wide, scrolling page, and gifts spread into four columns. Same ink, red, and marker marks as the phone app. Names, gifts and prices are made-up; product pictures are placeholders.

1. Family: who's on the list

The tab bar is gone. Navigation lives in the rail, so every screen keeps the same frame. "I'm getting" moves into a side column so a shopper sees what's left to buy without leaving the home page.

2. A person's list

Four columns of gifts. The floating button becomes a real button in the page header. Marker loop = most wanted; check + handwriting = claimed (givers and managers only, never the list's owner).

3. One gift

Picture and details sit side by side and fill the page, so the page is no longer as narrow as the photo. The claim box, store link, and management actions stay where phone users already know them.

4. Adding a gift

A centered dialog over the list instead of a full-screen sheet, so you can see the list you're adding to. Paste a link, and the name, price, and picture fill in. Esc closes it.

5. I'm getting

Rows become a table-like list with room for the store and status, grouped by person with a total each.

How it behaves

What changes in the code

  • One shell component swaps the bottom tab bar for the rail at ≥ 900px. Routes and data don't change.
  • Detail page becomes a two-column grid; the width bug disappears because the page owns the width, not the photo.
  • Add gift opens as a dialog at desktop widths and as today's sheet on phones.
  • The floating "Add for…" button becomes a header button on desktop.
  • Notification and install prompts become a small card at the bottom of the rail.

Keeping what works

  • Same tokens: red #C8102E, ink, mustard, pine, Archivo Black + Atkinson Hyperlegible.
  • Targets stay ≥ 44px; hover adds a hard ink shadow (no soft glow), and every hover state has a keyboard focus ring in mustard.
  • Secrecy is untouched: the owner never sees claims on any screen here.
  • Stitching along the rail edge is the one new flourish: the red is a book cover, the white is the page.
